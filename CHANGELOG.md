# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog,
and this project adheres to Semantic Versioning.

## [1.0.0] - 2026-10-30

### Added
- NumPy-only SMB simulation engine with configurable numerical modes and flow models.
- Interactive local web app for setup, execution, and results exploration.
- Built-in Case 1, Case 2, and Case 3 configurations.
- Validation scripts for benchmark comparison and sensitivity checks.
- Test suite with quick sanity checks.
- Cross-platform launch scripts and package metadata for open-source distribution.
